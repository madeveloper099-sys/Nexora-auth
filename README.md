# Nexora Auth

A premium animated Login and Registration System built with PHP, MySQL, HTML, CSS and JavaScript.

## Features

- Premium modern UI
- Login and Registration
- Secure password hashing
- Password show/hide
- PHP Session Authentication
- MySQL Database Connection
- Responsive Design
- Animated Background Effects

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Requirements

- XAMPP
- PHP 8+
- MySQL

## Installation

1. Download or clone this repository.
2. Move the project folder into XAMPP's `htdocs` directory.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import the `database.sql` file.
6. Check database credentials in `index.php`.
7. Open this URL in your browser:

`http://localhost/nexora-auth/`
